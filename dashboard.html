Fine-tune a local model

Create your own LoRA model from a pretrained chat model. Training and future replies run on this computer. The base model may download once from Hugging Face; this does not use a hosted inference API. Use JSONL conversations, or choose a dataset folder containing paired .txt captions; caption text is converted into examples and video files are counted but not sent to the language model. Start with at least two examples and a small instruct model. Training examples and progress are saved in this project; if Uvicorn restarts, the app resumes from its latest checkpoint when available. A normal browser refresh does not stop training.
